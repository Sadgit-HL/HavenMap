Context menus: every element that has one

Seven menus in the playmat, plus the card menu that the ⋯ button opens. Each is shown open next to its element. Every entry is editable text.

How to use: change the text of any entry, press × to delete it, and use the dashed buttons at the bottom of a menu to add an action, a header or a separator. When you are done, press Export entries at the bottom and send me the JSON (or describe the changes in words). I will then rewire the functions in app.js. Renaming an entry only changes the text; the function it runs stays the same, unless you tell me otherwise.

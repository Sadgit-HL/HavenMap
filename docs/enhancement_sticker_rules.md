+ Square: This type of mark can only receive a +1 sticker. However, if directly attached to a non‑summon move ability, the mark can receive a jump sticker instead.
+ Circle: This type of mark can receive any square enhancement sticker or any element sticker (including a “wild” element sticker).
+ Diamond: This type of mark can receive any square or circle enhancement sticker or any negative condition sticker.
+ Diamond+: This type of mark can receive any square or circle enhancement sticker or any positive condition sticker.
+ Hex: This type of mark can only receive a hex sticker.
+ Treat any enhancement dot on a Forgotten Circles or Jaws of the Lion ability card as a diamond, diamond+, or hex enhancement mark.

## Enhancement costs (Gloomhaven 2nd edition rules, Appendix D, page 65)

Each type of enhancement has a base cost. The cost is then modified by the ability it is applied to. Apply these modifiers one at a time, in order:

1. If the ability targets multiple figures or tiles, double the cost. This applies to abilities that summon or affect multiple allies or tokens and to abilities that can target multiple figures or tiles. It does not apply to target, area-of-effect hex, or element enhancements.
2. If the action has a lost icon and is not a summon action, halve the cost.
3. For each level of the ability card above level 1, add 25 gold to the cost.
4. For each enhancement already on the action, add 75 gold to the cost.

Enhancements that do not fit the chart: treat damage traps as Attack +1 (50 gold), healing traps as Heal +1 (30 gold), and the movement of tokens and tiles as Move +1 (30 gold).
